# docs/

La página interactiva. GitHub Pages la publica desde esta carpeta
(*Settings › Pages › Deploy from branch › main › /docs*).

- `index.html`: página completa (HTML, CSS y JavaScript en un solo archivo).
- `og.png`: imagen de vista previa al compartir el enlace (1200 × 630).
- `datos.js`: series anuales por celda + clases de color. Lo genera `analysis/03_series_anuales.R`;
  sin él la página muestra un aviso.
